# РЕПЕРКА НАПИВЕННАЯ 🎤

Браузерный баттл-тренажёр памяти на React, TypeScript, Webpack и Emotion. Восемь уровней, пять испытаний на строку и финальная читка всего текста.

## Запуск

Установите Node.js 22 и выполните команды из корня проекта.

```sh
npm ci
npm start
```

Откройте [игру на порту 8080](http://127.0.0.1:8080/).

```sh
npm run typecheck
npm run build
```

Готовая статическая сборка появится в `dist/`.

## Как считается прогресс

- Разминка знакомит со строкой. Три задания с пропусками, сборка строки и читка дают суммарно 110 XP за уровень.
- С карты можно повторять открытые уровни и снова получать XP. Первая победа в финале даёт 150 XP.
- В финале вводите каждый панч с новой строки и добавьте «Раунд!» отдельной девятой строкой. Пустые строки, регистр, пунктуация, лишние пробелы и разница между «е» и «ё» игнорируются.
- Браузер хранит текущий этап, опыт, достижения и статистику. «Новый баттл» сбрасывает игровой прогресс после подтверждения.

## Публикация на GitHub Pages

1. Отправьте исходный код и `package-lock.json` в репозиторий GitHub.
2. В репозитории откройте **Settings → Pages** и выберите **GitHub Actions** в разделе **Build and deployment → Source**.
3. В **Actions** запустите **Deploy to GitHub Pages** через **Run workflow** для ветки `main`. Следующие push в `main` будут запускать публикацию автоматически.
4. После успешного запуска откройте адрес из окружения `github-pages` в выполненной задаче `deploy`.

Workflow устанавливает зависимости через `npm ci`, проверяет TypeScript, собирает игру и публикует каталог `dist/`. Ссылки на ассеты относительные, а переключение экранов происходит внутри SPA, поэтому игра работает и по адресу с именем репозитория в пути.
